# dr-claire-site

Personal site for Dr. Claire M. Hennigan, M.D. Hosted on GitHub Pages via the `madmaxlax` account.

**Live URL:** https://madmaxlax.github.io/dr-claire-site/

## Stack

Plain HTML + CSS + vanilla JS. No build step, no framework, no dependencies. Edit files and push — Pages deploys automatically from `main /`.

- `index.html` — single-page site
- `css/styles.css` — all styles (CSS custom properties, no preprocessor)
- `js/scripts.js` — mobile nav toggle, scroll-spy, fade-in animations
- `assets/img/` — profile photo (`profile.jpg`) and favicon

## Design

Warm editorial aesthetic. Cormorant Garamond display serif + DM Sans body. Forest sidebar (`#1e2e24`), warm ivory background (`#faf8f4`), bronze accents. Fixed sidebar on desktop, hamburger drawer on mobile (≤900px).
